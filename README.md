# Experiment 10: BPSK, QPSK, and DPSK Modulation

## 📑 Overview
This experiment explores coherent and differential phase modulation schemes, specifically **Binary Phase Shift Keying (BPSK)**, **Quadrature Phase Shift Keying (QPSK)**, and **Differential QPSK (DQPSK)**. It investigates the impact of carrier phase offsets on coherent detection, demonstrates the phenomenon of phase ambiguity, and utilizes phase trajectory plots to understand the necessity of pulse shaping in practical transmitters.

---

## 🎯 Objectives
1. Implement and compare coherent BPSK and Gray-coded QPSK modulation/demodulation.
2. Implement differential encoding and decoding for DPSK to resolve phase ambiguity.
3. Test the system's resilience against constant phase offsets (10°, 30°, 60°, and 90°).
4. Visualize and analyze phase trajectories to understand the impact of unfiltered vs. filtered signals.
5. Compare the Bit Error Rate (BER) performance of coherent and differential schemes.

## 📚 Theoretical Background & Concepts Used

### 1. Coherent Phase Modulation (BPSK & QPSK)
* **BPSK**: Uses two phases separated by 180° to represent binary 0 and 1. It is the most robust binary modulation scheme but requires strict phase synchronization.
* **QPSK**: Transmits two bits per symbol by utilizing four phases separated by 90°. To minimize the probability of bit errors when noise causes a symbol to cross a decision boundary, **Gray coding** is used. In Gray-coded QPSK, adjacent constellation points differ by only one bit (e.g., 00, 01, 11, 10).

### 2. Phase Ambiguity and Differential Encoding (DPSK)
* **Phase Ambiguity**: Coherent receivers rely on a local oscillator to recover the carrier phase. If the carrier recovery loop locks onto a phase offset (e.g., 90° or 180°), the entire constellation rotates, causing a cyclic shift in the decoded bits.
* **Differential Encoding (DPSK)**: Instead of encoding information in the *absolute* phase of the carrier, DPSK encodes information in the *phase difference* between consecutive symbols. Because a constant phase offset affects all symbols equally, the phase difference remains unchanged, making DPSK immune to phase ambiguity.

### 3. Phase Trajectory and Pulse Shaping
* **Unfiltered QPSK**: When using rectangular pulses, the signal transitions instantaneously between constellation points. A 180° phase shift forces the trajectory to pass directly through the origin `(0,0)`, causing the signal amplitude to drop to zero. This requires highly linear (and inefficient) power amplifiers.
* **Filtered QPSK**: Applying a pulse-shaping filter (like Root Raised Cosine) smooths the transitions, forcing the trajectory to curve *around* the origin, maintaining a more constant envelope.

## 💻 How the Code Works

The Python script is structured into sequential experiments, utilizing NumPy for fast vectorized operations and Matplotlib for clear visualizations.

### Step-by-Step Workflow:
1. **Modulation & Demodulation**: 
   * *Coherent*: Maps bits to absolute phases. Demodulation uses `np.angle()` and quadrant mapping.
   * *Differential*: Encodes bits as phase shifts relative to the previous symbol. Demodulation calculates the phase difference between consecutive symbols.
2. **Phase Ambiguity Validation**: Injects a fixed 90° phase offset into the transmitted QPSK signal. The coherent decoder's output is compared against the DPSK decoder's output to prove that DPSK rejects the offset.
3. **Trajectory Generation**: Generates a sequence of QPSK symbols. The unfiltered signal is created via zero-order hold (`np.repeat`), while the filtered signal is generated by passing the I and Q components through a Root Raised Cosine (RRC) filter.
4. **BER Simulation**: Sweeps $E_b/N_0$ from 0 to 10 dB, calculating the BER for BPSK, QPSK, DBPSK, and DQPSK, and overlays them with their theoretical bounds.

## ⚠️ Discrepancies, Reasons, and Mitigations

During the development and analysis of this simulation, specific physical and theoretical discrepancies were addressed.

### Discrepancy 1: Coherent QPSK Fails Under Phase Offset (Phase Ambiguity)
* **Observation**: When a 90° phase offset was applied to the coherent QPSK receiver, the Bit Error Rate skyrocketed to ~50%, and the decoded bits were completely wrong.
* **Reason**: Coherent detection relies on absolute phase. A 90° rotation shifts the constellation points into the wrong decision quadrants (e.g., `00` maps to `01`, `01` to `11`, etc.). This is the classic "phase ambiguity" problem in carrier recovery.
* **Mitigation**: Implemented **Differential QPSK (DQPSK)**. By decoding the *difference* in phase between consecutive symbols rather than the absolute phase, the constant 90° offset cancels out, perfectly recovering the original bits (barring the first reference symbol).

### Discrepancy 2: Unfiltered QPSK Trajectory Crossing the Origin
* **Observation**: The initial phase trajectory plot showed straight lines crossing directly through the `(0,0)` origin, forming an "X" shape.
* **Reason**: This is mathematically correct for unfiltered (rectangular pulse) QPSK. When the phase shifts by 180° (e.g., from top-right to bottom-left quadrant), the signal must pass through zero amplitude. However, this is physically undesirable for RF transmitters.
* **Mitigation**: Added a **Root Raised Cosine (RRC) pulse shaping filter** to the visualization. The updated plot shows both the unfiltered (crossing origin) and filtered (curving around the origin) trajectories side-by-side, demonstrating why practical systems always use pulse shaping.

### Discrepancy 3: Gray Coding Mapping Verification
* **Observation**: Initial testing of the QPSK demodulator showed that a single symbol error caused two bit errors.
* **Reason**: The constellation mapping was not using Gray coding. Adjacent symbols differed by two bits (e.g., `00` and `11`).
* **Mitigation**: Explicitly implemented the standard Gray code mapping (`00` $\rightarrow$ $\pi/4$, `01` $\rightarrow$ $3\pi/4$, `11` $\rightarrow$ $-3\pi/4$, `10` $\rightarrow$ $-\pi/4$). This ensures that noise pushing a symbol into an adjacent quadrant results in only a single bit error.
